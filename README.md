# Редактор каталога блюд

React + Vite: адаптивный редактор блюд для браузера и будущего Telegram Mini App. Не зависит от Telegram SDK и работает как обычная веб-страница. Можно добавить до 10 фотографий к блюду (JPEG, PNG, WebP до 10 МБ), обрезать свободно, в формате 1:1 или с любым заданным соотношением сторон, удалить фото и назначить главное. Исходное фото сохраняется отдельно: кнопка «Изменить фото» открывает текущую обрезанную версию для дальнейшей обрезки и смены соотношения сторон, а «Сбросить к исходному» подгружает оригинал в то же окно редактирования. Галерея на карточке и в просмотре блюда переключает фотографии каждые 3 секунды, главное всегда первое. Фото новых блюд загружаются при сохранении; изменения фото существующих блюд применяются сразу. Остатки не редактируются.

Формы и проверка полей используют React Hook Form; запросы и кэширование блюд — TanStack Query, хуки расположены в `src/hooks/`. Компоненты сгруппированы в `src/components/{auth,catalog,editor}/`, вспомогательные функции — в `src/utils/`, HTTP-клиент — в `src/api/`. Кэш очищается при выходе администратора.

## Локальный запуск

Запустите API из соседнего репозитория `_va_back_products` на порту 3001, затем:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Vite проксирует `/api` на локальный API. В текущей локальной установке токен администратора: `local-only-change-before-deploy` (только для разработки). Токен хранится в памяти вкладки, не в localStorage.

## Docker Compose / Coolify

После установки Docker: `docker compose up --build -d`; страница откроется на `http://localhost:8080`, а запросы пойдут на локальный API `http://localhost:3001`. Для этого в настройках API добавьте `http://localhost:8080` к `CORS_ORIGIN` (через запятую) и перезапустите API; это требуется и при использовании backend Compose. Docker в текущем окружении отсутствует, Compose не проверен исполнением.

Для Coolify подключите этот репозиторий отдельно как Dockerfile/Compose. Установите **build argument** `VITE_API_URL=https://<домен-api>` (полный публичный HTTPS-адрес API, без `/api`), соберите образ и направьте домен фронта на порт 80 контейнера. На API установите `CORS_ORIGIN` равным точному адресу фронта. В Vite переменные `VITE_*` встраиваются при сборке: после смены адреса API нужен rebuild. HTTPS обязателен для Telegram Mini App; SDK и авторизация через Telegram будут добавлены при интеграции с ботом, не подменяйте административный токен клиентским секретом.

Проверка сборки: `npm run build`. Форматирование: `npm run format`; проверка без изменений: `npm run format:check`. Правила заданы в `.prettierrc.json`.
